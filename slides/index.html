Microsoft Foundry

A managed platform for models, agents, tools, identity, observability, and publishing.

What is Microsoft Foundry?

Model catalogchoose and deploy models for reasoning, voice, and tools
Agent runtimehosts prompt agents, workflow agents, and hosted agents
Toolsweb search, file search, code interpreter, MCP, and custom functions

Resolve remote agents via HTTP


AIAgent ResolveA2AAgent(string envVar, string cardPath = "/.well-known/agent-card.json")
{
    var url = Environment.GetEnvironmentVariable(envVar);

    var httpClient = new HttpClient { BaseAddress = new Uri(url) };
    var resolver = new A2ACardResolver(httpClient.BaseAddress!, httpClient, agentCardPath: cardPath);

    return resolver.GetAgentCardAsync().Result.AsAIAgent(httpClient);
}

Architecture evolution

From agent as a tool to agent as a skill

Keep the specialist boundary and distributed execution—remove the second model hop.

Same domain boundary, different runtime

Agent as a toolAgent as a skill
DiscoverA2A Agent Card becomes a functionMCP index advertises a skill description
Load contextStart the specialist agentLoad the selected SKILL.md
Choose operationSpecialist model chooses its toolAdvisor model chooses a skill resource
ExecuteTool runs behind the specialistDynamic resource runs on the MCP server
Model callsAdvisor + specialistAdvisor only

“Agent as a skill” maps the agent's bounded context to a portable skill; it does not put an agent inside the skill.

The remote skill contract

Each .NET MCP service publishes three progressive layers.

Advertiseskill://index.json
name + description
Loadskill://weather/SKILL.md
domain instructions
Actskill://weather/forecast/{hours}
dynamic resource
Groundresource handler calls live APIs and services

[McpServerResourceType]
public sealed class WeatherSkillResources(
    WeatherDataService weather)
{
    [McpServerResource(
        UriTemplate =
            "skill://weather/forecast/{hours}",
        MimeType = "application/json")]
    public Task<string> GetForecast(int hours) =>
        weather.GetForecastAsync(hours);
}

Reading a resource executes its handler remotely. The URI template carries the parameters.

The advisor receives skills, not provider tools
